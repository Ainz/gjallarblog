Gjallarblog **0.06-beta.1** refines the beta settings and public navigation. It removes custom menu markup/styling and public entry-number labels, clarifies Restore versus deletion, limits recent entries to five, and offers three date formats with a current example and reference link. The beta also supports historical publication dates in gallery time, image paste/upload with safe re-encoding, captions, alternative text, size and placement controls, previous/next entry navigation, simplified naming and title cleanup. The editor defaults to centered block images without text wrapping; left/right block and inline placements are available. It retains theme-aware image styling and safe formatting help for headings, rules, quotations and code. Uploads use PNG, JPEG or WebP, require GD with WebP support, and are bounded by file size and pixel count. Future publication dates are rejected.

**Publication status:** this source version was merged into GitHub `main` on 23 October 2026. It has not been tagged or published as a GitHub release, and no downloadable 0.06-beta.1 package is attached. The latest packaged release remains 0.04-alpha.1.

The release also groups settings into journal identity, layout and placement, entry details, and site navigation. One plain-text Journal name now labels the menu link, journal heading and return links. Choose Hidden, Before content or After content separately for home and album pages; ordering remains in Piwigo’s menu manager. Removal has its own tab and explains that Restore preserves journal content. Journal RSS links are removed; the old feed address redirects to Piwigo’s core feed. Public journal styles inherit theme colors and keep layout rules scoped to Gjallarblog; custom themes may still need CSS adjustments.

Settings → Plugin removal shows live entry and image counts and requires confirmation. Data is kept by default. A webmaster can explicitly erase entries, images and settings by typing Gjallarblog. The screen verifies that the plugin directory is gone before erasing data or claiming success. Piwigo deactivation, uninstall and plugin-manager deletion preserve data for reinstalling.

No 0.06-beta.1 ZIP or checksum is published as a GitHub release. A local test archive can be built with `python tools/build-package.py`; it does not create a tag or publish a release. Piwigo's built-in update checker discovers revisions through the Extension Manager, so an update notification requires a registered extension and published revision. Existing display choices migrate to equivalent placement values. See README and validation documentation for tested combinations and limitations.
